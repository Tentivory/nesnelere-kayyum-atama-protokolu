# NESNELERE KAYYUM ATAMA PROTOKOLÜ

## Dünyanın En Gerekli Yazılımı

Bu depo, insanlığın yüzyıllardır çözemediği en kritik sorunu ele almaktadır:  
**Evdeki, ofisteki ve hayali nesnelere resmi kayyum atama ihtiyacı.**

Artık kahve fincanınız, ayakkabı bağcığınız, uzaktan kumandanız veya  
buzdolabının içindeki o şüpheli artakalan yemek, korumasız ve yönetimsiz  
durumda kalmak zorunda değil.

### Neden Bu Proje Hayati Öneme Sahiptir?

- Nesneler pasif kalıyor.
- İnisiyatif almıyorlar.
- Potansiyellerini gerçekleştirmiyorlar.
- Bazen de fazla gürültü yapıyorlar.

Bu durumda tek çözüm vardır: **Kayyum.**

Bu yazılım, bilimsel (aslında rastgele) yöntemlerle nesnenize  
en uygun geçici yönetimi atar ve size tamamen resmi görünümlü  
bir karar belgesi sunar.

### Kurulum ve Kullanım

```bash
python3 kayyum_atayici.py
```

veya doğrudan nesne belirterek:

```bash
python3 kayyum_atayici.py "sol çorap"
python3 kayyum_atayici.py "eski kumanda"
python3 kayyum_atayici.py "mutfak masası"
```

Program çalıştığında bürokratik süreçleri yavaş yavaş simüle eder,  
sonra size muhteşem bir resmi karar çıktısı verir.

### Özellikler

- Gerçek zamanlı bürokratik gecikme simülasyonu
- Rastgele ama son derece inandırıcı gerekçeler
- Resmi karar numarası üretimi
- Mühür ve damga sistemi
- %100 hayali koruma garantisi
